# Part C: the configuration given to CEA's simulator (cea_crossval.py config)

* Topology: interposer `I` 8 x 8 (our footprint model) without processing elements (`custom_pe: [999]`: no valid id, so no PE), chiplets `C0`..`C3` 4 x 4 (chiplet c at footprint (c mod 2, c div 2)), 4 vertical links per chiplet at our slots N (1,0), E (3,1), S (2,3), W (0,2), each to the interposer router under it. 2 VCs, 4-flit buffers, 8-flit packets, 32-bit flits; uniform random traffic over the 64 chiplet PEs (CEA `TRAFFIC_RANDOM`, injection `-pir R poisson`: Bernoulli with rate R per cycle, as our tables).
* `routing_algorithm: DEFT` (CEA's Routing_DEFT: the paper's Algorithm 1 and Rules 1-3). Variant `rr`: `route_using_selection_strategy: false`, so the VC at the boundary round-robin point is DeFT's own round-robin (`selectVCOut`); variant `bl`: `true` with `selection_strategy: BUFFER_LEVEL`, CEA's adaptive VC choice among the offered VN0/VN1.
* Exit selection (`vertical_links_selection: down`, one VL per source router, consulted once at the source): the exit of `luts/v23/lut_2x2_0x0000.yaml` (`entries`, the v1-v21 exit used by every DeFT variant of this repository). CEA keys the exit by the source router alone, our LUT by (source router, destination chiplet): 64 of 64 routers have the same exit for all 3 destination chiplets; the majority is used elsewhere.
* Entry selection (`vertical_links_selection: up`, per interposer router and destination chiplet, consulted once at the interposer router where the packet lands): the `destination_entry` of the LUT's `entries` for the pairs whose exit lands there (the v1-v21 entry = DeFT-B's): 29 of 48 (landing router, destination chiplet) cells have a single entry over those pairs. **The paper's per-destination-router entry (DeFT-P, `entries_by_destination`) cannot be expressed in CEA's format**, whose entry is a function of the landing router and the destination chiplet; the cross-validation reference is therefore DeFT-B (same VN rules as DeFT-P), and DeFT-P is shown next to it.
* Interposer routers that are not landing routers keep CEA's default (nearest VL); they are never consulted for an entry.
* Overrides (CEA asserts that a boundary source takes its own link): none
* Both simulators record the latency of the head flit from its generation timestamp (`Stats::receivedFlit`, identical code), so the latencies compare directly. CEA divides the per-IP throughput by all 128 routers; it is recomputed here per chiplet router from the network throughput. The router pipelines differ in detail (CEA imposes no 2-cycle head rule), which the saturation-load band absorbs.
